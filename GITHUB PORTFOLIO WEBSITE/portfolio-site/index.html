FLAGSHIP PROJECT

Intelligent Depression Risk Prediction for University Student Wellbeing

A full-stack data science approach integrating SQL analytics, Excel feature engineering, explainable machine learning, and executive Power BI reporting — deployed as a live, containerised web app.

From raw psychometric survey data to a deployed, explainable risk model.

Live app → GitHub repo

Nearly 1 in 2 students in the dataset screened positive for clinically significant depression (PHQ-9 ≥ 10) — yet most university wellbeing systems remain reactive. This project builds the alternative: a leakage-audited machine learning pipeline trained on 1,408 UK university students' validated screening scores (PHQ-9, GAD-7, PSS, UCLA-3, SBQ-R, and more), explained end-to-end with SHAP, and surfaced through a 3-page executive Power BI dashboard for non-technical stakeholders.

SQL Server Microsoft Excel Python / Pandas Scikit-Learn SHAP Power BI · DAX Docker Streamlit
Key finding

Anxiety, stress, and loneliness — not demographic factors like sex or course type — were the strongest predictors of depression risk, confirmed independently across correlation analysis, feature importance, and SHAP value distributions. That reshapes where a university should target intervention resources.

HOW THE PROJECT WAS BUILT

Six stages, one pipeline.

The actual sequence data moved through, from a raw CSV export to a live prediction served over Docker.

  1. 01

    SQL analysis

    19 diagnostic queries in SQL Server profiling prevalence, severity, and institutional risk using TRY_CAST-safe type coercion and composite risk scoring.

  2. 02

    Excel feature engineering

    Clinically-labelled severity bands and NHS-aligned recommendations, built with nested logic and VLOOKUP for non-technical auditability.

  3. 03

    Python & machine learning

    Leakage-safe feature selection, five models benchmarked, and a Gradient Boosting classifier selected on ROC-AUC and recall — not raw accuracy.

  4. 04

    Explainable AI

    SHAP summary and feature-importance analysis, confirming the model isn't relying on demographic proxies — a fairness signal, not just a performance one.

  5. 05

    Power BI reporting

    A 3-page executive dashboard with advanced DAX (CALCULATE, RANKX, drill-through, row-level security) built for a university welfare manager, not a data analyst.

  6. 06

    Deployment

    Model serialised with joblib, wrapped in a Streamlit app, containerised with Docker, and shipped as a live, publicly accessible prediction tool.
